The project has pivoted from its first-version "screen-recording review tool" to a real-time AI coach + automatic review dual-entry architecture. The full perception → decision → broadcast → UI loop runs end to end — the OBS virtual camera drives OBSCapture · FrameMonitor triggers on key frames · VLMClient emits WorldState · _infer_decision_context fires six decision types · DecisionLLM returns single-point advice within 3 seconds · advice_server broadcasts over WebSocket · overlay_ui floats a translucent card above the MuMu window. When the match ends, LocalLLMAnalyzer is triggered to auto-synthesize a review markdown into reports/. 100% local inference · zero cloud API cost · a more robust compliance posture than the ADB route.
